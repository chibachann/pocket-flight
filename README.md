# Pocket Flight

スマートフォンのブラウザで動く、依存ライブラリなしの簡易フライトシミュレーターです。
Canvas 2D の上に最小限の3Dパイプライン（透視投影・ニアクリップ・画家のアルゴリズム）を自前で実装しており、
WebGLもビルド工程も使いません。ファイルをそのまま静的配信すれば動きます。

## 遊ぶ

公開URL: https://chibachann.github.io/pocket-flight/

`main` へのプッシュごとに GitHub Actions（`.github/workflows/pages.yml`）が自動で公開します。

## 手元で動かす

```bash
npm start
```

表示されたURLを開きます。同一LAN内のIPアドレスも表示されるので、PCで起動してスマホの実機から開けます。
スマホでは**縦向き・横向きのどちらでも**プレイできます。プレイ中に回しても、視野角・HUD・操作エリアが向きに追従します。

```bash
npm start -- --port=8080   # ポートを変える
```

Node.js 18以上が必要ですが、npmの依存パッケージはありません（`npm install` は不要）。
静的ファイルなので、Netlify・Vercel・GitHub Pages などにそのまま置いても動きます。

## 操作

実機の操縦桿と同じ向きに固定しています（下へ引く＝機首上げ、押す＝機首下げ）。

| 操作 | 内容 |
| --- | --- |
| 画面左側をドラッグ | 仮想スティック。左右でロール、下へ引くと機首上げ・上へ押すと機首下げ |
| 縦バー（横向きは右端、縦向きは右下） | スロットル（上ほど高出力） |
| 端末を傾ける | 「傾き」操作を選んだ場合。手前に倒す（引く）と機首上げ・奥へ倒すと機首下げ。開始時の姿勢が中立になります |
| 矢印キー | ピッチ・ロール（PC） |
| W / S | スロットル増減（PC） |
| A / D | ラダー（PC） |
| P / C / R | ポーズ / 視点切替 / やり直し（PC） |

操縦アシストはありません。バンクをかければそのまま旋回が続き、宙返りや背面飛行も自由にできます
（アシストで自動的に水平へ戻されて曲がれない、といったことはありません）。

## ゲームルール

- 滑走路の南端に停止した状態から始まります。スロットルを上げて加速し、
  速度が乗ったら機首を上げて離陸してください（滑走路全長1400m、目安10秒・滑走距離200〜300mで浮上します）。
- 光るリング（シアン色が次の目標）を順番にくぐります。通過ごとに 1000 点。
- **タイムアタック**：制限時間90秒（離陸に要する時間を見込んで従来の75秒から延長）。リング通過ごとに15秒加算。
- **フリーフライト**：時間制限なし。
- 全リング通過後に滑走路へ着陸して停止するとミッション完了（ボーナス 5000 点＋残り時間×25）。
- 接地は「滑走路の上」「沈下率7m/s未満」「バンク20度未満」「速度396km/h未満」で成立します。
  条件を外れた接地、および滑走路以外への接地は墜落です。離陸のローテーション中は、
  機首を大きく上げても（速度が離陸速度未満のうちはピッチの上下限チェック自体を行わないため）
  それだけでは墜落しません。また地上を走っている間はロール入力が無効化され、
  誤操作でバンクして接地クラッシュすることはありません。
- リング未通過のうちに滑走路へ降りた場合はゲームオーバーにならず、そのまま再離陸できます。

## 構成

```
index.html        画面構成（キャンバス＋メニュー等のオーバーレイ）
styles.css        UIのスタイル。縦向き・横向き・狭い画面向けの調整を含む
scripts/serve.mjs 動作確認用の依存なし静的サーバー
src/
  main.js         エントリポイント。DOMのUIとゲームループの接続
  game.js         状態遷移、スコア、カメラ、固定ステップの物理更新
  aircraft.js     飛行力学（揚力・抗力・推力・重力）と接地判定
  controls.js     タッチ／傾き／キーボード入力の抽象化
  renderer.js     Canvas 2D 上の3D投影・クリップ・フォグ
  scene.js        地形（LOD付き）・滑走路・樹木・雲・リング・自機の描画
  terrain.js      手続き的な地形フィールドと地表色
  course.js       滑走路諸元とリングコースの生成・通過判定
  hud.js          計器表示（水平儀、速度、高度、方位、警告など）
  math.js         ベクトル・回転・補間のユーティリティ
  audio.js        WebAudioによるエンジン音・風切り音・効果音
```

## 実装メモ

- **座標系**：X＝東 / Y＝上（高度） / Z＝北。機体姿勢は正規直交基底（forward/right/up）で保持し、
  毎ステップ直交化してジンバルロックと数値誤差を避けています。
- **飛行モデル**：迎角から揚力係数を求め、失速角を超えると急減させます。
  横滑り角による風見安定で旋回が自動的に協調するようにしています。
  操舵は対気速度に比例した角速度指令（レートコマンド）方式です。
- **地形**：値ノイズのfBm＋尾根ノイズ。カメラ周辺を3段のLODグリッドで描き、
  粗いリングから順に描くことで境界の隙間をなくしています。高さ0未満は水面として平坦に扱います。
- **描画負荷**：平均フレーム時間を監視し、重いときは自動で内部解像度を下げます（`renderer.qualityScale`）。
- **デバッグ**：`window.pocketFlight` から `game` / `renderer` / `controls` / `audio` を参照できます。

## 調整したいとき

- 機体性能：`src/aircraft.js` の `SPEC`（推力、翼面積、舵の効きなど）
- コースの長さ・制限時間・離陸開始位置：`src/game.js` の `MODES` / `TAKEOFF_START_MARGIN`
- 地形の起伏：`src/terrain.js` の `OCTAVES`
- 描画距離とフォグ：`src/renderer.js` の `FAR` / `FOG_START`、`src/scene.js` の `RINGS`

## 制限

- 風・乱気流、他機、着陸装置の出し入れはありません。
- 地形は無限に続きますが、リングコースは飛行場周辺に生成されます。
- iOSで「傾き」操作を使う場合、端末の設定で「モーションと画面の向きのアクセス」を許可する必要があります。
